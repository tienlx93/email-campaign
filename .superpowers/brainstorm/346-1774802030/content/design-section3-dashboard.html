Agent implementation notes

  • Date filter bar: preset pills (Last 30 days default) + custom from/to date pickers · "Grouped by" label auto-computed and shown read-only: ≤30d→Day, 31–90d→Week, >90d→Month
  • Section title: "Performance Overview · {fromDate} – {toDate} · grouped by {day|week|month}"
  • KPI cards (6): Total campaigns · Scheduled · Emails Sent · Success Rate · Open Rate · Failed Rate — all filtered by date range
  • Percentages: calculated in FE (success = sent/total_recipients, open = opened/sent, failed = failed/total_recipients)
  • Chart 1 (Volume Trend): stacked BarChart per period · series: draft count, scheduled count, sent count · tooltip: label + count + % of total
  • Chart 2 (Delivery Performance): stacked BarChart per period · only periods with sent campaigns · series: sent, opened, failed · tooltip: count + %
  • Charts library: @mui/x-charts BarChart component
  • Backend endpoint: GET /dashboard?from=&to=&groupBy=day|week|month — returns kpi object + volumeSeries array + deliverySeries array (raw counts only, no percentages)
  • TDD: unit tests for the service query logic before implementation
