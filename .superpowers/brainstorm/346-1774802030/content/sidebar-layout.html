A — Icon Collapse

Sidebar shrinks to icon-only strip (≈48px) when collapsed. Icons always visible — no content is hidden. Great for power users who want quick nav without menus. Top bar still shows user avatar + theme toggle.

When collapsed: full-width content. When open: sidebar overlays.

B — Full Hide / Overlay

Sidebar is fully hidden by default on desktop. A hamburger (☰) in the top bar opens it as an overlay slide-in. Content uses full width. Cleaner for content-heavy pages, more like a mobile-first admin.

C — Persistent + Collapse Toggle

Sidebar is always visible on desktop (no full hide). A toggle button collapses it to icon-only. User avatar lives at the bottom of the sidebar. Top bar is minimal — just theme toggle + user avatar. Most common enterprise admin pattern.

My recommendation: Option C (Persistent + Collapse Toggle) — matches the enterprise admin portal feel the user described, is the most familiar pattern for MarTech tools, and gives the user avatar + theme toggle a natural home in the top bar. Option A is a close second and very practical too.
