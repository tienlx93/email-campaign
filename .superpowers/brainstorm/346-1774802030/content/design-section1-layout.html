Key rules for the agent implementing this

  • Sidebar width: 220px expanded · 56px collapsed (icon-only, label hidden)
  • Hamburger toggle: in top bar — toggles sidebar between expanded/collapsed; state stored in Redux (persists across navigation)
  • Nav groups: "Main Menu" (Dashboard, Email Campaigns) · "Account" (User Settings)
  • User avatar: 2-letter initials from name, color deterministically derived from name (hashed to one of 6 palette colors)
  • Top bar dropdown: links to /settings and dispatches logout — same logout behavior as current code
  • Light/dark mode: toggle stored in Redux + localStorage; applies dark class to <html>; shadcn/ui + Tailwind dark mode via CSS variables
  • Icons: react-icons/bs (Bootstrap Icons) throughout — BsGrid, BsEnvelope, BsPerson, BsList, BsMoon, BsSun etc.
  • Active nav item: left border accent (#3b82f6) + slightly lighter background on the active route
  • Route /: redirects to /dashboard (new default)
