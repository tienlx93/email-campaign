Agent implementation notes

  • Table columns: Campaign Name · Subject (truncated) · Status badge · Recipients · Scheduled At · Created At
  • Search: debounced 300ms, sends search query param to GET /campaigns?search=&status=&page=&limit=
  • Filter: status dropdown ("All statuses" | Draft | Scheduled | Sent) — sends status query param
  • Backend change: extend existing GET /campaigns to accept optional search (ILIKE on name and subject) and status query params; follow TDD
  • Row click: navigates to /campaigns/:id (same as current card click)
  • Sorting: default newest first (created_at DESC) — no sortable columns needed
  • Pagination: same RTK Query hook, reset to page 1 when search/filter changes
  • Empty/no-results state: "No campaigns match your search" when filtered; existing empty state when zero campaigns total
